Deepfake Detection using GenAI Models

May 2025

Abalone Age Prediction

Feb 2024

Built a regression pipeline to predict the age of abalone shellfish based on physical features. This project demonstrates my skills in data preprocessing, feature engineering, and machine learning model selection.

I applied and compared multiple models including Linear Regression, Random Forest, XGBoost, and CatBoost to find the most accurate prediction method. Used RMSLE as the evaluation metric and achieved a performance score of 0.21 on test data.

Technologies Used:

Python Machine Learning Pandas Scikit-learn
